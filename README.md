# JAMP 2 — Trust Layer

JAMP 2 checks bounded factual claims against inspectable source observations and preserves the evidence and decision trail.

**Proof over confidence. AI searches; JAMP verifies.**

v1 scope: MOEX ISS and CoinGecko providers, raw evidence integrity, bounded verdicts, audit trail, minimal API and Dashboard.

JAMP 2 is not a model router, agent platform, messaging bot, or general-purpose chat service. JAMP 1 remains the historical source repository; JAMP 2 has no runtime dependency on it.
